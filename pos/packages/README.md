# pos/packages

POS ilovalari uchun umumiy Dart paketlari (bu yerda hozircha ular yaratilmagan, faqat reja):
- `pos_core` — chek, stol, smena, chegirma mantiqi;
- `pos_sync` — internetsiz ishlash: lokal baza va sinxronlash;
- `pos_hardware` — printer, kassa qutisi, skaner (escpos, sunmi, windows);
- `pos_fiscal` — fiskal chek integratsiyasi uchun joy;
- `pos_ui` — sensor ekran komponentlari.
Qurilishi: 3-bosqich (docs/ROADMAP.md). Stek: Dart / Flutter.
