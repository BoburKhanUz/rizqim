# packages/ts

Veb-ilovalar uchun umumiy TypeScript paketlari: `api-client` (OpenAPI'dan yaratilgan klient), `ui` (dizayn tokenlari va komponentlar), `staff` (xodim ekranlari uchun umumiy kod).
Qurilishi: 1-bosqich (docs/ROADMAP.md). Stek: TypeScript; `customer/miniapp` va `partner/web` ishlatadi.

- `api-client` — `@rizqim/api-client`, `packages/api-spec/openapi.json` dan yaratiladi (README ichida).
- `ui` — `@rizqim/ui`: dizayn tokenlari va umumiy React komponentlari (manba kod sifatida ulanadi, [ui/README.md](ui/README.md)).
- `staff` — `@rizqim/staff`: buyurtma statuslari va amallari, formatlar, uz/ru matnlar, API qatlami va TanStack Query hook'lari; Mini App xodim sahifalari va hamkor web ishlatadi (manba kod sifatida ulanadi, [staff/README.md](staff/README.md)).
